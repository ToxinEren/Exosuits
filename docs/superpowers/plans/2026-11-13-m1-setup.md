# Milestone 1 — Setup del progetto: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un solo repository che produce quattro jar (1.20.1 Forge, 1.20.1 Fabric, 1.21.1 Fabric, 1.21.1 NeoForge) con un item di prova registrato, icona e nome, costruiti da CI a ogni push, più la checklist per avviarli sul PC.

**Architecture:** approccio B del design: un solo source tree, Stonecutter 0.9.8 con quattro varianti `<mc>-<loader>`, Architectury Loom 1.17.493 come plugin di build per tutti i loader, Architectury API per registrazione/tab, Mojang mappings. I file di `platform/` (entrypoint dei loader) sono interi blocchi condizionali Stonecutter; `compat/` contiene le uniche condizioni di versione; tutto il resto è codice comune.

**Tech Stack:** Gradle 9.9.0 (wrapper), JDK 21 per eseguire Gradle, bytecode `--release 17` (1.20.1) e `21` (1.21.1); Stonecutter 0.9.8; Architectury Loom 1.17.493; Architectury API 9.2.14 / 13.0.11; Fabric Loader 0.20.1, Fabric API 0.92.12+1.20.1 / 0.116.18+1.21.1; Forge 1.20.1-47.4.29; NeoForge 21.1.266; GeckoLib 4.8.4 / 4.9.3 (solo dichiarato, usato da M3); JUnit 5 (da M2); GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-12-redstone-exoframes-design.md` (§4 approcci, §5 architettura, §7 decisioni, §8 criteri di M1) e `docs/superpowers/specs/claude-doc-2026-11-04-redstone-exoframes.md` (design di gioco).

## Global Constraints

- Mod id `redstone_exoframes`; nome "Redstone Exoframes"; package radice `com.toxineren.exoframes`; gruppo Maven `com.toxineren`; versione mod `0.1.0`.
- Quattro varianti Stonecutter, nomi esatti: `1.20.1-fabric`, `1.20.1-forge`, `1.21.1-fabric`, `1.21.1-neoforge`; variante attiva (vcs) `1.21.1-neoforge`.
- Nessun import di `net.minecraft.*`, `net.fabricmc.*`, `net.minecraftforge.*`, `net.neoforged.*`, `dev.architectury.*` in `com.toxineren.exoframes.core`.
- Commenti condizionali Stonecutter (`//? if ...`) ammessi solo in `com.toxineren.exoframes.compat` (condizioni di versione) e in `com.toxineren.exoframes.platform` (condizioni di loader, un file per loader, intero file).
- Mappature Mojang ufficiali su tutte le varianti; nessun refmap.
- Il repo è un unico Gradle: i Maven di modding servono solo i propri gruppi (filtri `content`/`exclusiveContent`), Maven Central per ultimo, con `systemProp.org.gradle.internal.repository.max.tentatives=8` e `initial.backoff=1500` (Central risponde 429 a intermittenza dal proxy cloud).
- Nessun nome, forma, texture o testo riconducibile a Halo o Fallout; asset placeholder generati da script, licenza asset "tutti i diritti riservati", codice MIT.
- Ogni task termina con `git commit` sul branch `main` e `git -c push.negotiate=true push`.

## Review Focus

1. Un jar che contiene i metadati di un altro loader (es. `fabric.mod.json` dentro il jar Forge): Forge/NeoForge lo ignorano ma Fabric prova a caricarlo e il jar risulta "doppio" nei modpack misti. Atteso: ogni jar contiene solo i propri metadati. Test: `tools/check_jars.sh` (Task 5) fallisce se trova un file estraneo.
2. `pack.mcmeta` con `pack_format` sbagliato per la versione: il client scarta le risorse del mod (icone viola, lingua mancante) senza crash. Atteso: 15 nei jar 1.20.1, 34 nei jar 1.21.1. Test: `tools/check_jars.sh`.
3. `Ids` che usa il costruttore di `ResourceLocation` su 1.21.1: il costruttore è privato, `NoSuchMethodError` al primo uso. Atteso: `fromNamespaceAndPath` su 1.21.1, costruttore su 1.20.1. Test: `javap -c` sulla classe compilata di ciascuna variante (Task 4).
4. Su Forge 1.20.1 Architectury richiede `EventBuses.registerModEventBus` prima di qualsiasi `DeferredRegister.register()`, altrimenti `IllegalStateException` all'avvio. Atteso: l'entrypoint Forge lo chiama nel costruttore prima di `RedstoneExoframes.init()`. Test: non unit-testabile qui; voce esplicita nella checklist di avvio (Task 6) e asserzione `grep` in `tools/check_sources.sh` (Task 4).
5. Intervallo di versione Minecraft nei metadati che esclude la versione reale (es. `[1.21,1.21.1)` o `>=1.21.1 <1.21.1`): il loader rifiuta il mod con un messaggio poco chiaro. Atteso: Fabric `>=1.20.1 <1.21` / `>=1.21 <1.22`; Forge `[1.20.1,1.21)`; NeoForge `[1.21.1,1.22)`. Test: `tools/check_jars.sh` confronta i valori espansi nei jar.
