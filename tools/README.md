# tools

`gen_placeholders.py` rigenera in modo deterministico le texture placeholder
(`redstone_cell.png` 16x16 e `icon.png` 64x64). Solo libreria standard di Python 3.

    python3 -I tools/gen_placeholders.py

I disegni sono originali e procedurali. Eseguendo lo script due volte si
ottengono file identici byte per byte.
